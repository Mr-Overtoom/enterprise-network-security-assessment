# enterprise-network-security-assessment
Enterprise Network Security Assessment & Threat Analysis

Network vulnerability assessment and threat analysis using Nmap, Zenmap, and Wireshark.

Overview:
This project demonstrates a network security assessment performed in a controlled lab environment. The assessment involved network discovery, vulnerability identification, packet capture analysis, and remediation recommendations.

Tools Used
- Nmap
- Zenmap
- Wireshark

Key Findings
- Vulnerable Windows Server deployment
- Anonymous FTP access
- Unencrypted HTTP communications
- Network reconnaissance activity
- SSH protocol weaknesses
- Potential DoS activity

Skills Demonstrated
- Vulnerability Assessment
- Network Security Analysis
- Threat Detection
- Risk Evaluation
- Technical Documentation

Disclaimer: 
This project was conducted in a controlled educational environment for defensive cybersecurity learning purposes.
